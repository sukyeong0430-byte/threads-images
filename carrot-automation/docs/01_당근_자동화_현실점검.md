# 01. 당근 자동화 현실점검 — 무엇이 되고, 무엇이 안 되는가

> 강의 1교시에 이 내용을 먼저 깔아야 합니다.
> 여기서 기대치를 정확히 맞춰야 나머지 강의가 신뢰를 얻습니다.

## 결론 먼저

**당근에 글을 자동으로 올려주는 공식 API는 없습니다.**

Threads(Meta), 인스타그램, 유튜브는 공개 발행 API가 있어서 코드로 100% 자동 발행이
가능합니다. 당근은 다릅니다. 비즈프로필도, 광고센터도, 외부 개발자가 글을 게시할 수 있는
API를 열어두지 않았습니다.

## 그럼 매크로/크롤링으로 하면 되지 않나?

기술적으로는 가능합니다. Selenium, Appium, 안드로이드 접근성 서비스로 앱을 조작하면
글이 올라갑니다. **하지만 하지 마세요.**

당근 운영정책은 매크로·자동화 프로그램 사용을 위치조작·허위 동네인증·피드 도배와 같은
등급의 위반으로 봅니다. 심각한 위반 시 **당근 서비스 전체 이용 정지(최대 1825일 = 5년)**
이고, 제재된 계정은 해제하지 않는다고 명시돼 있습니다.

소상공인에게 당근 계정은 단순 SNS 계정이 아니라 **동네 인증 + 매너온도 + 단골 목록이 붙은
영업 자산**입니다. 몇 년 쌓은 걸 글 자동화 하나 때문에 날리는 건 수지가 안 맞습니다.

**수강생에게 매크로를 가르치면, 수강생 가게를 태우는 강의가 됩니다.**

## 그래서 자동화 못 하나요?

합니다. 다만 **자동화의 경계를 발행이 아니라 '발행 직전'에 둡니다.**

사장님이 당근에 글 하나 올리는 데 실제로 드는 시간을 쪼개보면:

| 단계 | 소요 | 자동화 |
|---|---|---|
| 뭘 올릴지 정하기 | 15분 | ✅ 완전자동 |
| 문구 쓰기 | 20분 | ✅ 완전자동 |
| 이미지 만들기 | 25분 | ✅ 완전자동 |
| 영상 만들기 | 60분+ | ✅ 완전자동 |
| **당근 앱에서 붙여넣고 게시** | **1분** | ❌ 사람 |
| 다른 채널에도 올리기 | 15분 | ✅ 완전자동 |

**2시간짜리 일이 1분으로 줄어듭니다.** 남는 1분이 바로 당근의 API 부재이고,
그건 없애는 게 아니라 **가장 짧게 만드는 것**이 정답입니다.

## 당근에서 공식적으로 쓸 수 있는 것

| 수단 | 링크 | 자동화 가능성 |
|---|---|---|
| 비즈프로필 (무료 업체 등록·소식) | business.daangn.com | 수동 게시만 |
| 당근 광고 (셀프서브) | ads-center.business.daangn.com | 대시보드에서 집행 |
| 당근 광고 전문가모드 | ads-pro.business.daangn.com | 대량 집행 시 검토 |
| 파트너/대행사 API | 비공개, 별도 제휴 필요 | 규모 있으면 문의 |

광고는 **돈으로 도달을 사는 것**이고, 소식·동네생활은 **콘텐츠로 단골을 쌓는 것**입니다.
이 강의는 후자에 집중하고, 광고는 "콘텐츠가 검증된 뒤 태우는 기름"으로 다룹니다.

## 강의에서 쓸 한 문장

> "당근 자동화는 '자동으로 올리는 기술'이 아니라,
>  **올릴 게 매일 준비돼 있게 만드는 기술**입니다."
