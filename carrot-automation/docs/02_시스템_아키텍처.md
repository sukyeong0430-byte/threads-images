## 왜 이렇게 나눴나

### 1) 콘티를 먼저, 소재는 나중
"이미지부터 만들자"가 흔한 실수입니다. **무슨 말을 할지가 정해지면 이미지는 따라옵니다.**
콘티(conti.json)가 단일 진실 원천(single source of truth)이고, 카드·영상·채널별 본문은
전부 여기서 파생됩니다. 콘티만 고치면 아래가 전부 다시 만들어집니다.

### 2) 콘텐츠 기둥(pillar) 순환
할인만 올리면 단골이 피로해지고, 감성글만 올리면 매출이 안 납니다.
6개 기둥을 강제로 돌립니다.

| 기둥 | 목적 |
|---|---|
| 신메뉴·대표메뉴 | 팔고 싶은 걸 직접 보여준다 |
| 이번 주 혜택 | 당장 방문할 이유를 만든다 |
| 사장님 이야기 | 가게를 신뢰하게 만든다 |
| 단골 후기 | 남의 말이 내 말보다 세다 |
| 운영 안내 | 헛걸음을 막아 불만을 줄인다 |
| 동네 밀착 인사 | '우리 동네 가게'로 각인시킨다 |

### 3) 채널별 톤 분리
같은 소재라도 채널마다 말투가 다릅니다. `gen_conti.py`의 `to_daangn / to_threads /
to_instagram`이 그 차이를 코드로 박아둔 부분입니다.

- **당근**: 해시태그 최소. 동네 이름과 위치가 핵심. 광고 냄새가 나면 이웃이 등을 돌립니다.
- **스레드**: 첫 줄 후킹이 전부. 짧게, 해시태그 2~3개.
- **인스타**: 줄바꿈 넉넉히, 해시태그 다수, 릴스(short.mp4)와 세트.

### 4) 영상은 프레임을 직접 그린다
ffmpeg의 `zoompan`/`xfade` 필터 대신 **PIL로 프레임을 한 장씩 그려 ffmpeg에 넘깁니다.**
필터 문법은 수강생이 읽을 수 없지만, "0.4초 동안 앞 장면과 섞는다"는 파이썬 다섯 줄은
읽을 수 있습니다. 강의용으로는 이쪽이 압도적으로 낫습니다.

## 기술 스택 (전부 무료)

| 역할 | 도구 | 비용 |
|---|---|---|
| 콘티·카피 생성 | Python (+ 선택적으로 Claude API) | 무료 / 종량 |
| 이미지 생성 | Pillow + 나눔스퀘어라운드 | 무료 |
| 영상 생성 | ffmpeg | 무료 |
| 폰트 | 나눔글꼴 (상업적 이용 가능) | 무료 |
| 스케줄링 | cron / Claude Code Routine | 무료 |
| 전달 | 구글드라이브 공유폴더 | 무료 |

## 확장 포인트 (강의 심화편 소재)

1. **콘티 생성을 Claude API로 교체** — 템플릿 문구 대신 가게별 실제 문맥 반영
2. **실사진 자동 선택** — assets/photos 에서 메뉴명 매칭
3. **성과 기록 루프** — 발행 후 조회수 입력 → 잘 된 기둥 비중 자동 증가
4. **스케줄 자동화** — 매주 월요일 06시에 다음 주 콘티 생성 + 드라이브 업로드
5. **당근 광고 연계** — 콘텐츠 중 반응 좋은 것만 광고비 집행
