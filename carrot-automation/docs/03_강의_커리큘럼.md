# 03. 강의 커리큘럼 초안

## 강의 정체성

- **제목(안)**: 당근 마케팅 자동화 — 하루 2시간 쓰던 걸 1분으로
- **대상**: 동네에서 가게를 운영 중이고, 당근 비즈프로필은 만들었는데 관리를 못 하는 사장님
- **선수 지식**: 없음. 컴퓨터로 폴더를 열 수 있으면 됩니다.
- **약속하는 결과물**: 수료 시점에 **본인 가게 한 달치 콘텐츠(콘티 12건 + 카드 12장 + 쇼츠 3편)**
  가 폴더로 나와 있고, 다음 달치는 명령어 한 줄로 다시 뽑을 수 있는 상태

## 이 강의가 팔리는 이유 (차별점)

시중 "당근 자동화" 강의 대부분은 매크로를 가르칩니다. 계정이 정지되면 환불도 못 받습니다.
이 강의는 **계정을 지키면서 일을 90% 줄이는 쪽**입니다. 1교시에 그 차이를 명확히 밝히고
시작하는 것 자체가 신뢰가 됩니다.

---

## 4주 과정 (주 1회 × 2시간)

### 1주차 — 현실점검과 소재 설계
| 시간 | 내용 |
|---|---|
| 20분 | 당근에 API가 없다는 사실, 매크로가 왜 위험한지 (운영정책 원문 같이 읽기) |
| 30분 | 자동화의 경계선 긋기: 무엇을 기계에 맡기고 무엇을 사람이 하는가 |
| 40분 | **실습**: 내 가게 `store.json` 채우기 (대표메뉴·후기·동네·CTA) |
| 30분 | 콘텐츠 기둥 6개 이해하기 — 왜 할인만 올리면 망하는가 |

> 과제: 단골 후기 3개, 메뉴 사진 5장 모아오기

### 2주차 — 한 달치 콘티 자동 생성
| 시간 | 내용 |
|---|---|
| 30분 | 파이썬·터미널 최소한만 (설치 → 명령어 한 줄) |
| 40분 | **실습**: `gen_conti.py` 실행 → 내 가게 12건 콘티 생성 |
| 30분 | 생성된 문구 고치기 — 기계 말투를 내 말투로 |
| 20분 | 채널별 톤 차이 (당근 vs 스레드 vs 인스타) |

> 과제: 콘티 12건 전부 본인 말투로 다듬기

### 3주차 — 카드 이미지와 쇼츠 영상
| 시간 | 내용 |
|---|---|
| 30분 | **실습**: `make_card.py` → 카드 12장 |
| 20분 | 브랜드 컬러·폰트 바꿔보기, 실사진 넣기 |
| 40분 | **실습**: `make_short.py` → 쇼츠 3편 |
| 30분 | 스마트폰 촬영 가이드 (조명·각도·15초 규칙) |

> 과제: 본인 가게 쇼츠 3편 완성

### 4주차 — 발행과 반복 시스템
| 시간 | 내용 |
|---|---|
| 30분 | **실습**: `make_package.py` → 폴더를 내 폰으로 받기 (구글드라이브) |
| 20분 | 당근 비즈프로필 소식 실제 게시 (다같이 1건 올려보기) |
| 30분 | 다른 채널 완전자동 발행 (Threads API 연결) |
| 20분 | 매주 자동 실행 걸기 (cron / 예약 작업) |
| 20분 | 성과 보는 법과 다음 달 개선 루프 |

---

## 1일 특강 버전 (3시간)

1주차 20분 + 2주차 실습 + 3주차 카드 실습 + 4주차 발행까지 압축.
영상 제작은 시연만 하고 자료로 제공.

## 강사가 미리 준비할 것

- [ ] 수강생 노트북에 Python + ffmpeg 설치 스크립트 (Windows/Mac 각각)
- [ ] 예시 가게 `store.json` 3종 (음식점 / 미용실 / 학원) — 업종별 감 잡게
- [ ] 결과물 샘플 폴더 (1주차에 "4주 뒤 이게 나옵니다" 보여주기용)
- [ ] 당근 운영정책 원문 캡처 (매크로 위험 설명용)
- [ ] 설치 실패 대비 클라우드 실행 환경 (Colab 등) 백업

## 가격·패키지 (검토용)

| 구성 | 내용 | 비고 |
|---|---|---|
| 기본 | 4주 과정 + 스크립트 전체 | 본 커리큘럼 |
| 업종팩 | 업종별 콘티 템플릿 추가 | 미용실·학원·카페·헬스장 |
| 대행 | 첫 달 콘텐츠를 강사가 세팅해줌 | 업셀 |
| 심화 | Claude API 연동, 성과 기반 자동 개선 | 2기용 |

## 주의: 강의에서 절대 하면 안 되는 것

- ❌ 매크로·자동 등록 프로그램 배포하거나 시연
- ❌ "당근 API로 자동 발행됩니다" 라고 표현 (사실이 아님)
- ❌ 수강생 당근 계정 정보를 받아서 대신 조작
- ✅ 대신: "발행 직전까지 자동, 게시는 1분" 을 일관되게 강조
